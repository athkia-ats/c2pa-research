# CR Content Credentials Prototype

This is a static GitHub Pages-ready prototype.

## Files

- `index.html` - page and interaction logic
- `assets/feed.png` - the full feed image

## Run locally

Open `index.html` in a browser. Click the Content Credentials banner near the top to open the history dialog.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. In GitHub: **Settings -> Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Save. GitHub will provide the public URL.

The image is kept as one complete image; the transparent clickable hotspot is placed over the Content Credentials banner.
